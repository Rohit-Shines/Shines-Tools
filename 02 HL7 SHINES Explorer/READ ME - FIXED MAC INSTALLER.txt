HL7 SHINES Explorer 1.2.0 - Corrected One-Click Package
=======================================================

This package fixes the Mac installation issue that displayed:
"The Python runtime path is missing. Please reinstall the application."

Mac users should open:
  Mac OS Installation
and double-click:
  1 - INSTALL HL7 SHINES EXPLORER.command

Windows users should open:
  Windows Installation
and double-click:
  1 - INSTALL HL7 SHINES EXPLORER.bat
