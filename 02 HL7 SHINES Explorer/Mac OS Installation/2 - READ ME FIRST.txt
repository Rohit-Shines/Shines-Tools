HL7 SHINES EXPLORER 1.2.0 - MAC OS INSTALLATION
=================================================

ONE-CLICK INSTALLATION
----------------------
1. Keep this complete "Mac OS Installation" folder together.
2. Double-click: 1 - INSTALL HL7 SHINES EXPLORER.command
3. Wait until the application opens.

The installer automatically removes an older or incomplete installation
before installing the corrected application.

The application is installed here:
  Home folder > Applications > HL7 SHINES Explorer.app

APPLE SILICON MACS
------------------
M1, M2, M3, M4 and newer Apple Silicon Macs use the included native app.
No Python download is required.

The installer also detects Apple Silicon correctly when Terminal is running
through Rosetta and incorrectly reports x86_64.

INTEL MACS
----------
The installer uses the included cross-platform application. If a compatible
Python runtime is not already installed, it downloads the official Python
installer and macOS asks once for an administrator password.

The Intel launcher can now automatically recover if its saved Python path is
missing or if Python was upgraded after installation.

IF macOS BLOCKS THE .command FILE
---------------------------------
Control-click the INSTALL file, choose Open, and then choose Open again.
This can happen because the installer is not Apple-notarized.

UNINSTALL
---------
Double-click: 3 - UNINSTALL HL7 SHINES EXPLORER.command

NOTE ABOUT A TERMINAL .zshrc ERROR
---------------------------------
A message such as:
  ~/.zshrc:19: unmatched '
comes from an existing syntax error in your personal Terminal configuration.
It is separate from HL7 SHINES Explorer and does not mean the installer file
is damaged.

PRIVACY
-------
HL7 files are processed locally. Do not commit real patient data or PHI to
a public GitHub repository.
