HL7 SHINES EXPLORER 1.2.0 - WINDOWS INSTALLATION
=================================================

SIMPLE INSTALLATION
-------------------
1. Keep this complete folder together.
2. Double-click: 1 - INSTALL HL7 SHINES EXPLORER.bat
3. Wait until the application opens.

The installer automatically:
- Downloads and verifies the official Python runtime when needed.
- Installs everything for the current Windows user.
- Creates a Desktop shortcut.
- Creates Start-menu shortcuts.
- Associates .hl7 and .er7 files with HL7 SHINES Explorer.

No administrator password is normally required.

REQUIREMENTS
------------
- 64-bit Windows 10 or Windows 11.
- Internet access during the first installation.

WINDOWS SECURITY MESSAGE
------------------------
If Windows displays a warning for the BAT file, choose More info and then
Run anyway only when the folder came from the official Rohit-Shines GitHub
repository. The installer verifies the downloaded Python runtime signature.

UNINSTALL
---------
Use either method:
- Double-click: 3 - UNINSTALL HL7 SHINES EXPLORER.bat
- Windows Settings > Apps > Installed apps > HL7 SHINES Explorer > Uninstall

PRIVACY
-------
HL7 files are processed locally. Do not commit real patient data or PHI to
a public GitHub repository.

NOTE ABOUT FILE TYPE
--------------------
Windows does not run macOS .command files. The correct one-click installer
on Windows is the included .bat file.
