# Security policy

## Supported version

Security fixes are applied to the latest release line.

| Version | Supported |
|---|---|
| 1.2.x | Yes |
| Earlier | No |

## Reporting a vulnerability

Do not open a public issue containing exploit details, PHI, credentials, internal addresses, certificates, or production identifiers.

Contact the repository owner privately through the GitHub profile. Include:

- affected version and operating system;
- reproducible synthetic test data;
- impact;
- suggested mitigation when known.

## Network safety

The MLLP tools must be used only against systems the user is authorized to test. TLS certificate verification is enabled by default when TLS is selected.
