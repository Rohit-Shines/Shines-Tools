# Privacy

HL7 Shines is designed for local processing.

## Local operations

The following operations run on the user's computer:

- parsing;
- field reference lookup;
- editing;
- validation;
- statistics;
- comparison;
- sample generation;
- local Assistant summaries;
- file import/export;
- preferences.

## Network operations

The application opens a network connection only after the user explicitly:

- sends the selected message through the MLLP sender; or
- starts the local MLLP listener.

The project has no telemetry, advertising SDK, crash-upload service, analytics service, cloud AI call, or automatic update request.

## PHI responsibility

HL7 messages may contain protected health information. Users must follow their organization's privacy, security, retention, access-control, and approved-device requirements. Do not attach real messages to public GitHub issues. Reproduce defects using synthetic data.
