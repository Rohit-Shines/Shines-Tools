Workout Version 3.1 User Guide

Custom controls, true seconds mode, multiple profiles, coaching and background reminders.

Front view

Squats, presses, curls, kicks and arm circles.

Side view

Push-ups, planks, squat holds and sit-ups.

Seconds mode

The timer begins when a timed pose is stable.

Quick start

  1. Open Workout Version 3.
  2. Select or create a profile.
  3. Choose Automatic or Manual mode.
  4. Enable only exercises planned for the session.
  5. Start the workout and press Q to finish.

Editable shortcut keys

Edit the Shortcut column in the Dashboard and save. Every shortcut must be unique. Reserved keys are 0, M, X, D and Q.

Timed exercises

Plank, squat hold, overhead stretch and forward fold are measured in seconds. Use Manual mode for initial testing and keep the required joints visible.

Background reminders

Open the Reminders tab, choose an interval and enable reminders. The popup can launch the app, snooze or dismiss even when the app is closed.

Coaching

The Coaching tab compares recent form scores with earlier samples and reports the most common stored correction. It waits for enough data before claiming improvement. This is pose-estimation guidance, not medical advice.
