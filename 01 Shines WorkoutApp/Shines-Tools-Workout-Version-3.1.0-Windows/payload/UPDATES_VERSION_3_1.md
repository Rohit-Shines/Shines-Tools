# Workout Version 3.1 Patch

This patch adds:

- Editable profile-specific shortcut keys
- Live fractional seconds mode for timed holds
- Multiple profile creation and profile cloning
- Coaching and improvement statistics
- Background movement-break reminders
- In-app Help, Coaching and Reminders tabs
- Static HTML and Markdown user guides
- Feedback in portable exports

The patch does not replace the Python environment, models, database history, camera bridge launcher, or installed macOS application bundle.
