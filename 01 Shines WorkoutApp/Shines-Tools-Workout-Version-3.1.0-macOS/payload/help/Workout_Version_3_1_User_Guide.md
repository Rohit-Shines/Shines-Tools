# Workout Version 3.1 User Guide

## What is new

- Editable, profile-specific manual shortcut keys.
- Large live **SECONDS MODE** timer for plank, squat hold, overhead stretch and forward fold.
- Multiple profiles with separate counts, goals, preferences, shortcut keys and coaching history.
- Background movement-break reminders that can appear while the app is closed.
- Coaching and improvement statistics based on completed movements and stored form scores.
- Built-in Help, Coaching and Reminders tabs.

## Starting a workout

1. Open **Workout Version 3.app**.
2. Select a profile.
3. Choose **Automatic mode** or **Manual keyboard mode**.
4. In automatic mode, enable only the exercises planned for that session.
5. Click **Start workout**.
6. Press **Q** in the camera window when finished.

## Seconds mode

Timed exercises use seconds, not repetitions:

- Plank
- Squat hold
- Overhead stretch
- Forward fold

Use a side or 45-degree camera view and keep the required joints visible. The live window displays a large seconds timer once the pose is stable. A brief tracking loss is tolerated before the timer pauses.

## Custom shortcut keys

Open the Dashboard and edit the **Shortcut** column. Each shortcut must be unique.

Reserved application keys:

- `0` Automatic mode
- `M` Manual mode
- `X` Reset current exercise
- `D` Open report
- `Q` Finish and save

Click **Save preferences, shortcut keys, order and goals** after editing.

## Profiles

Use **Create profile** to add another person. You may copy the current profile's goals, exercise order and shortcut keys. Each profile has independent history and coaching data.

## Movement reminders

Open the Reminders tab, choose an interval and enable the background reminder. A macOS LaunchAgent checks once per minute and can show a popup even when Workout Version 3 is closed. The popup can launch the app, snooze, or dismiss.

## Coaching report

The Coaching tab uses recorded completed movements. It compares the latest 20 form-score samples with the previous 20. The app does not claim improvement until enough data exists. The feedback is pose-estimation guidance, not medical advice.

## Camera diagrams

### Front view

Use for squats, presses, curls, kicks and arm circles. Keep the full body inside the frame.

### Side view

Use for push-ups, planks, squat holds and sit-ups. Keep shoulders, hips, knees and feet visible.

## Accuracy checklist

- Use even front lighting.
- Avoid a bright window directly behind you.
- Keep all required joints in the camera frame.
- Use manual mode when testing a timed exercise.
- In automatic mode, enable only exercises planned for the current workout.
- Move through a complete start, movement and return cycle.
